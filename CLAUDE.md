# Nukkad — instructions for any Claude session

Before doing anything, read in this order: `PLAN.md` → `NOTES.md` → `BUGS.md`.

- The product owner's rules are in PLAN.md §1. Follow them exactly.
- Stop for feedback only after Phases 1, 3 and 5. Report each phase in 5 lines or fewer.
- Update NOTES.md and BUGS.md at the end of every phase, then commit.
- Open data only (OpenStreetMap, open elevation). No Google Maps, no brand logos, no ripped assets.
- Never use the Geolocation API. Never store voice. Store only display name, room id, avatar choice.
- Be honest: say what does not work yet. Never fake a feature.
