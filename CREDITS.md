# Credits

Nukkad uses only open data and open-source code. Everything you see in the world —
buildings, trees, lamps, colours — is generated by our own code from that data.
There are no downloaded 3D models, textures, fonts, sounds or logos.

## Map data

**© OpenStreetMap contributors** — roads, buildings, parks, water and trees.
Licence: Open Database License (ODbL) 1.0 — https://www.openstreetmap.org/copyright

- Fetched through the public Overpass API, once per place, then cached.
- The credit "© OpenStreetMap contributors" is shown on every screen that shows the world
  (and, from Phase 6, burned into saved photos).
- `tools/fixtures/a_12921_77695_600/overpass.json.gz` is a saved copy of OpenStreetMap data
  for the built-in test area and is under the same ODbL licence.

## Elevation data

**Terrain Tiles** (the "Terrarium" tiles created by Mapzen, hosted on AWS Open Data) — ground heights.
https://registry.opendata.aws/terrain-tiles/

The tiles combine several public elevation sources that differ by region (for example SRTM,
3DEP, GMTED2010 and ETOPO1). The exact credit lines the sources ask for are listed at
https://github.com/tilezen/joerd/blob/master/docs/attribution.md

- TODO before public launch: copy the exact required wording from that page into the in-game credits screen.
- `tools/fixtures/a_12921_77695_600/terrarium-*.png` are four saved tiles for the test area.
